# Oxford Words — персональний PWA-тренажер

Безкоштовний стартовий проєкт без backend, акаунтів і платних API. Слова та прогрес зберігаються в IndexedDB браузера.

## Важливо про дані
Цей starter **не містить готового Oxford 3000/5000 словника або вигаданих перекладів**. Щоб зберегти точність, імпортуйте CSV, сформований із перевірених даних. Офіційні списки й рівні CEFR шукайте на:
https://www.oxfordlearnersdictionaries.com/wordlists/oxford3000-5000

Перед повторним використанням чи поширенням даних перевірте умови Oxford. Українські переклади слід звіряти за окремими надійними словниковими джерелами та позначати статус перевірки.

## Формат CSV
Файл має бути UTF-8 і містити заголовки:
`word,part_of_speech,cefr,lists,translation_uk,example_en,source,translation_status`

Приклад структури (лише демонстраційний, не Oxford-дані):
`word,part_of_speech,cefr,lists,translation_uk,example_en,source,translation_status`
`sample,noun,A1,3000,зразок,,Перевірити словник,needs_review`

`lists` — `3000`, `5000` або обидва через крапку з комою. `translation_status` — наприклад `verified`, `needs_review`.

## Як запустити на комп'ютері
Для Service Worker потрібен HTTPS або localhost. У каталозі проєкту виконайте:
`python -m http.server 8000`
і відкрийте `http://localhost:8000`. Це локальний тест, не публікація.

## Як додати на iPhone
PWA для встановлення з Safari має бути доступний за HTTPS. Завантажте файли на статичний хостинг, наприклад GitHub Pages або Cloudflare Pages, потім відкрийте URL у Safari → Поділитися → На початковий екран.

## Поточні функції
- окремі екрани навчання, словника, статистики й налаштувань;
- SM-2 інтервальне повторення з чотирма оцінками (`Забув`, `Важко`, `Добре`, `Легко`), історією відповідей і денними лімітами;
- режими карток, тесту з чотирма варіантами, введення відповіді, складних слів і вільного перегляду;
- пошук українською та англійською, фільтри Oxford/CEFR/статусу, сортування, обране, нотатки та власні приклади;
- тематичні набори, прогрес за CEFR і списками, активність за 7 днів, точність і серії;
- попередній перегляд CSV, безпечне оновлення словникових даних без втрати прогресу, повна та персональна JSON-резервні копії;
- IndexedDB схеми версії 3 із міграцією старого прогресу й мережево-орієнтований Service Worker для швидкого отримання оновлень.

## Обмеження
- Застосунок навмисно не містить готових 3000/5000 записів.
- Дані не синхронізуються між пристроями.
- Перед очищенням даних браузера експортуйте повну JSON-копію.
